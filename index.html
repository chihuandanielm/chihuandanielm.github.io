Privacy & security details

I built this site to be a plain, quiet corner of the internet. It doesn’t set cookies, there’s no analytics or tracking, and there’s nothing to sign up for. I don’t collect your IP address, and I couldn’t see it even if I wanted to.

Under the hood it’s just files (pages, images, fonts) handed to your browser by GitHub Pages. No database, no login, no server code of mine. The only thing your browser keeps is a small note saying you’ve already watched Toby walk across the welcome screen, so he doesn’t do it again every time you reload. That note stays on your device and disappears when you close the tab.

A few outside services do touch your visit:

GitHub Pages
hosts the site, so it sees standard request info, including IP addresses, the way any host does. That stays with GitHub under their privacy statement.
Spotify
runs the music player in its own sealed-off frame. It may set its own cookies; this site doesn’t set any.
Formspree
only hears from you if you use the contact form. It gets your email and message, plus your IP for spam filtering.

On the security side, the page only runs code from this site, won’t load inside someone else’s frame, and doesn’t tell other sites where you came from when you click away. The fonts are hosted here, not by Google, and every photo had its location and camera data stripped before it went up.

If you spot something off, the contact form above reaches me directly. And if you’re curious how it’s put together, the source code is on GitHub.
